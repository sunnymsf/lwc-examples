The `lightning/analyticsAppFrameworkApi` module includes wire adapters and methods to work the Tableau Einstein app framework.

The wire adapters are:

-   getApp
-   getAppActivities
-   getAppActivity
-   getAppAssets
-   getApps
-   getTemplate
-   getTemplateConfig
-   getTemplates

The JavaScript methods are:

-   createApp
-   deleteApp
