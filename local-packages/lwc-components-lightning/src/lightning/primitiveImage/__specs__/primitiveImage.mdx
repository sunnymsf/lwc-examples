# Specification

## Overview

The Image component is a versatile and accessible image element designed for displaying images with optional configurations tailored to common use cases.

## Use Cases

Use the Image component to display images in your application while providing accessibility support and custom styling.

## Non-goals

- Handling image loading errors or fallback images.
- Providing advanced image manipulation or editing features.
- Image editing or manipulation features, such as cropping, resizing, or filtering.
- Support for image galleries, carousels, or other complex image layouts.
- Built-in lightbox or modal functionality for displaying images in an overlay.
- Handling image upload or storage functionality.
- Providing a comprehensive set of default styles or themes for the image component.

## Features

- Displays an image with a customizable src attribute to specify the image URL.
- Supports the srcset attribute to specify multiple image sources for different viewport sizes and resolutions, allowing the browser to choose the most appropriate image.
- Supports the sizes attribute to define the displayed image width based on the viewport width, optimizing the image loading for different screen sizes.
- Provides an API to set the aspect ratio of the image, ensuring the image maintains its proportions when resized.
- Ensures accessibility by supporting alternative text for screen readers and other assistive technologies.
- Allows the customization of the object-fit property to control how the image content is resized and positioned within the container.
- Validates image URLs and aspect ratios before applying them to the component to ensure proper rendering and avoid errors.
- Styling Hooks should be used to customize the appearance.
- Customization beyond Styling Hooks can be achieved through the CSS Shadow Parts API.

## API

### Properties & Attributes

| Attribute | Type     | Default Value | Description                                                                                                             |
| --------- | -------- | ------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `alt`     | `string` | `''`          | The alternative text used to describe the image.                                                                        |
| `fit`     | `string` |               | The object-fit CSS property.                                                                                            |
| `src`     | `string` |               | The URL of the image. An error will be logged if the URL is not a valid image URL.                                      |
| `ratio`   | `string` |               | The aspect ratio of the image. Accepts `square', `landscape`, `portrait`, `wide`, `ultrawide`, or a valid custom value. |
| `srcset`  | `string` |               | A comma-separated list of image sources with optional descriptors (width or pixel density).                             |
| `sizes`   | `string` |               | A set of media conditions and width descriptors to define the displayed image width per viewport.                       |

## Accessibility

The Image component supports the `alt` attribute, which should be used to provide alternative text describing the image. This text will be read by screen readers and is essential for accessibility.

## Internationalization

The Image component itself does not contain any text, but the `alt` attribute should support all languages.
