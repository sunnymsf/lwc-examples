The `lightning/uiListApi` (Beta/Deprecated) module provides the `getListUi` wire adapter.
`getListUi` gets list view records and metadata for a list view by:

-   List view API name
-   List view ID
-   API name of supported object

You can also get list view records and metadata for a most recently used list view by object. For this module's specification and examples, see the [Lightning Web Components Developer Guide](https://developer.salesforce.com/docs/platform/lwc/guide/reference-lightning-ui-api-list-ui).
